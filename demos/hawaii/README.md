# Hawaii demo

An end-to-end example: a real basemap style audited against real data.

- `data/` — vector sources (GeoJSON) for the demo extent.
- `styles/` — MapLibre style JSON variants, including deliberately
  inaccessible ones to exercise the auditor.

Both directories are placeholders until the style adapter lands (see
[../../docs/roadmap.md](../../docs/roadmap.md)).
